# Skills

Agent skills for the Straddle API.

## Install

Install the skills with the [`skills`](https://github.com/vercel-labs/skills) CLI:

```sh
npx skills add straddle-build/skills
```

This command installs the skills only, not the Straddle API and Docs MCP servers. To see the plugin packaging for Claude Code, Codex, and Cursor, which adds those servers, read [docs/packaging.md](docs/packaging.md).
